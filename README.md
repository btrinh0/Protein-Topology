# Protein Topology

Membrane Rule Audit is a Python package for measuring how protein variant
predictions reflect specified biological expectations.

Install directly from GitHub with Python 3.10 or newer and Git.

```sh
python -m pip install "membrane-rule-audit @ git+https://github.com/btrinh0/Protein-Topology.git@main#subdirectory=project6_membrane_variant_topology_audit/tools"
membrane-rule-panel --help
```

The [package guide](project6_membrane_variant_topology_audit/tools/README.md)
lists the commands, input formats, and synthetic examples.
