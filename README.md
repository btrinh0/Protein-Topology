# membrane-rule-audit v0.1.1

Python tools for auditing biological patterns in protein variant-effect scores.

The installable package, documentation, examples, and tests are in
[project6_membrane_variant_topology_audit/tools](project6_membrane_variant_topology_audit/tools).

    cd project6_membrane_variant_topology_audit/tools
    python -m pip install .

For the optional Biopython interface:

    python -m pip install ".[biopython]"

See the package README for command-line interfaces and offline examples.
See CITATION.cff for author and citation metadata.
