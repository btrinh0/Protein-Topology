The full import closure is included. In particular, figures_f4p_trial imports figures_sts, which imports figures_paper for shared paths. The full-fit builder imports b1_predictor_free, which imports feature definitions and backend helpers from a17_general_scorer. Those earlier modules contain older executable experiments. Their imported utilities are needed, while their main programs are outside the current reproduction order.

The standalone head takes 18 tabular features and 64 ProtT5 principal components. The shared historical feature table also stores AlphaMissense and ESM1b columns for mappings and comparisons. m4 selects the standalone feature list when fitting. Recreating the original retained-row table still uses the AlphaMissense-derived reference sequence and score-cell availability in a9. This dependency belongs in the data-preparation description.

Several statements need attention before calling the paper fully supported by its scripts.
